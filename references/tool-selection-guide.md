# 工具选型指南

工具选型的目标不是选“最先进”的工具，而是选当前企业能用、能维护、能形成闭环的工具。FDE 给工具建议时，必须说明企业规模、预算、IT 能力、数据量、现有使用习惯和维护责任。

## 决策树

```text
企业是否有稳定 IT 或数字化负责人？
├─ 没有
│  ├─ 员工主要用企业微信/微信 → Excel/WPS + 企业微信/智能表格优先
│  ├─ 员工主要用钉钉 → 钉钉表格/宜搭/审批流优先
│  ├─ 员工主要用飞书 → 飞书多维表格/审批/机器人优先
│  └─ 文件都在线下电脑 → 先做 Excel/WPS 标准化和文件夹流程
└─ 有
   ├─ IT/数字化人员 < 3 人 → 无代码/低代码 + 轻量 SaaS
   ├─ IT/数字化人员 ≥ 3 人 → 可考虑轻量自研 + 开源组件
   └─ 已有 ERP/CRM/WMS/MES → 优先做导出、对账、报表和异常层，不先替换系统

日处理数据量是否超过 1000 条？
├─ 否 → Excel/WPS/智能表格通常够用
└─ 是 → 需要数据库、SaaS 或现有系统接口

年预算是否低于 5 万？
├─ 是 → 现有办公套件 + 表格 + 脚本 + 轻量自动化
└─ 否 → 可评估无代码平台、轻量 SaaS 或局部定制
```

## 规模梯度

| 企业阶段 | 推荐组合 | 适合场景 | 不适合场景 |
|---|---|---|---|
| 微型团队 ≤10 人 | Excel/WPS + 微信/企业微信 + 共享文件夹 | 客户分级、销售跟进、简单对账、经营简报 | 多部门协同、权限复杂、数据量大 |
| 小型团队 10-50 人 | 企业微信/钉钉/飞书表格 + 表单 + 审批 | 线索收集、采购申请、客服工单、库存提醒 | 高并发业务、复杂财务、深度生产管理 |
| 中小企业 50-200 人 | 无代码/低代码 + 轻量 SaaS/WMS/MES/进销存 | 跨部门流程、异常提醒、报表汇总 | 核心系统高度定制、复杂生产排程 |
| 成长期 200-500 人 | 成熟 SaaS + 数据导出层 + 少量自研模块 | 财务、供应链、CRM、经营分析 | 频繁变化且无人维护的复杂系统 |
| 规模化 500 人以上 | ERP/数据平台/定制系统 + AI 模块 | 多门店、多工厂、集团化管理 | 没有数据治理基础时直接上 AI |

## 常见工具判断

- Excel/WPS：适合低成本起步、样本验证、公式规则固化；不适合多人同时复杂协作和权限严格场景。
- 企业微信/微信群：适合客户触达、标签、提醒和轻量协同；不适合沉淀复杂结构化数据。
- 钉钉/飞书：适合表单、审批、知识库、机器人和轻量流程；前提是员工已有使用习惯。
- 无代码/低代码：适合跨部门流程和表单驱动业务；风险是过度配置后没人维护。
- 金蝶/用友/进销存/SaaS：适合财务、库存、订单等标准流程；不适合强行承载所有个性化流程。
- 自研：适合已有稳定 IT 团队和明确高频核心流程；不适合需求还没跑清楚的早期试点。

## 输出要求

工具选型建议必须包含：

- 推荐工具组合。
- 为什么适合当前企业。
- 不适合什么情况。
- 需要谁维护。
- 第一版如何接入现有流程。
- 数据和权限风险。
- 未来升级路径。
