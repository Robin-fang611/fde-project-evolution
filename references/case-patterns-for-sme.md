# 从案例提炼的 FDE 可复用模式

这份文档从 8 个知名案例中提炼出可以跨行业、跨规模复用的操作模式，供 FDE 在项目中直接使用。

---

## 模式一：渐进三阶段（覆盖所有案例）

**几乎所有成功案例都按这个顺序走，跳步的失败了。**

```
阶段1: 数据上线（1-4 周）
  目标：把现在手工做的、口头说的，变成系统里有记录的
  做法：扫码报工、Excel 清洗结构化、企微标签体系、表单替代微信审批
  标准：关键流程数据能在一张表/一个看板上看到

阶段2: 流程固化（1-3 月）
  目标：把最痛的 1-2 个流程变成系统自动推动，不再靠人催
  做法：进销存联动、订单状态自动流转、异常自动预警
  标准：责任人不需要被提醒就知道自己要做什么

阶段3: AI 增强（看数据质量决定时机）
  目标：用 AI 替代重复判断、提取、分类、预警
  做法：智能订货建议、异常自动识别、评论分析反推改进
  标准：AI 输出能被人工快速复核
```

**反例**：那些一开始就要上大 ERP、大屏、AI 中台的企业，大多在阶段 1 就卡住了——不是技术问题，是数据根本没人录。

## 模式二：场景筛选的"双高双低"原则

**从案例中抽取的最值得做的场景特征：**

```
高痛感 × 高频次 × 低数据门槛 × 低决策风险

高痛感：老板/一线已经在抱怨，或者已经在出错
高频次：每天/每周反复发生（不是一个月一次）
低数据门槛：现有 Excel/微信/ERP 导出就能用，不需要先改造系统
低决策风险：AI 输出错了不会造成金钱或安全事故
```

**案例验证**：

| 案例 | 首个场景 | 是否符合双高双低 |
|---|---|---|
| 川航机械 | 工序报工（2 万步痛点 + 每天发生 + 扫码即可 + 只记录不决策） | 全部符合 |
| 中山五金 | 客户分级（老板记不住 + 每天沟通 + Excel 就有 + 分级错了可以调） | 全部符合 |
| 百果园 | 货架陈列监控（陈列空=丢单 + 实时 + 摄像头已有 + 错了补张照片） | 全部符合 |

**反例对照**：

| 场景 | 不符合哪条 | 结果 |
|---|---|---|
| AI 自动定价 | 高决策风险 | 价格错了直接亏损，老板不敢放权 |
| AI 排产全自动 | 高决策风险 + 低数据就绪 | 插单/缺料/设备故障情况太复杂，AI 无法处理 |
| 建大数据平台 | 低数据门槛不满足 | 第一步就要求整合所有系统，6 个月没产出 |

## 模式三：工具选型梯度

**不是"哪个工具好"，而是"这个规模最适合哪个"。**

| 企业规模 | 推荐工具组合 | 案例参考 |
|---|---|---|
| 微型（≤10人） | Excel + 企业微信 + 微信群 | 中山五金 |
| 小型（10-50人） | 企微智能表格 / 飞书多维表格 / WPS 智能表 | — |
| 中小（50-200人） | 无代码平台（简道云/轻流/明道云）+ 轻量 SaaS | 优克拉（钉钉生态） |
| 成长型（200-500人） | 成熟 SaaS（金蝶/用友/有赞）+ 自研模块 | 川航机械（自研链式系统） |
| 规模化（500人+） | 自研/定制 ERP + 数据中台 + AI 模块 | 百果园、钱大妈 |

**关键原则**：宁可降一级，不要升一级。一个 10 人团队强行上 SaaS ERP，结果就是只用 30% 功能、剩 70% 的钱白花。

## 模式四：ROI 的老板语言翻译表

**工程师说的 vs 老板听懂的 vs 一线关心的。**

| 技术语言 | → 老板语言 | → 一线语言 |
|---|---|---|
| 物料周转天数从 40 降到 5 | 压在仓库的钱从 2000 万变成 500 万 | 找料不需要跑仓库了 |
| 订单交付周期缩短 17% | 客户投诉少了，回款快了 | 不用每天被催进度了 |
| 复购率提升 47% | 不用拼命开发新客户也能增长 | 老客户更好说话了 |
| 审批流程从 2.6 天降到 0.8 天 | 采购不卡了，停工损失少了 | 不用追着领导签字了 |
| 新品成功率从 60% 到 92% | 试错成本降了，爆款更稳了 | 不用押注拍脑袋了 |
| OEE 从 72% 到 89% | 同样设备多产了 17% | 加班少了 |

**FDE 使用规则**：给老板汇报时只说老板语言，给一线培训时只说一线语言。绝不夹杂技术术语。

## 模式五：人机协同的四个级别

**案例中总结的 AI 参与度分级，适合用来设定客户预期。**

| 级别 | AI 做什么 | 人做什么 | 适用场景 | 案例 |
|---|---|---|---|---|
| L1：可视 | 汇总数据、生成图表 | 全部判断 | 老板日报、库存看板 | 川航初期 |
| L2：预警 | 标出异常、超标、逾期 | 处理异常 | 逾期订单、低库存、现金流 | 百果园现金流预警 |
| L3：建议 | 给出推荐选项 + 理由 | 选择、确认、微调 | 订货建议、排产方案、客户分级 | 钱大妈智能订货 |
| L4：执行 | 自动完成常规操作 | 抽查、处理例外、持续优化规则 | 自动发券、自动打标签、自动提醒 | 瑞幸私域 SOP |
| L5：全自动 | 自主决策闭环 | ❌ 中小企业不做 | — | — |

**默认规则**：永远从 L1 开始。客户信任 L1 了再提 L2。不要一上来就建议 L3/L4。

## 模式六：私域/客户运营的最小可跑模板

**从瑞幸 + 百果园 + 中山五金提炼的通用模板。**

```
第一步：把客户装进一个能触达的地方
  → 企业微信（比微信群好在：离职不丢客户、能打标签、能自动发消息）

第二步：给客户打 3 个标签
  → 价值标签：VIP / 普通 / 流失风险
  → 品类标签：买过什么
  → 行为标签：上次购买距今天数

第三步：设置 3 条自动化规则
  → 超过 N 天没买 → 自动发优惠券
  → 新客首单后第 3 天 → 自动发使用建议
  → 库存过剩单品 → 推给买过同类产品的客户

第四步：每周触达 ≤ 2 次（卖货 1 次 + 有价值内容 1 次）
  → 超过 2 次客户会屏蔽
```

**这是零成本可以直接跑的方案，对微型到小型企业足够用。**

## 模式七：FDE 项目判断信号灯

**从案例中总结的"这个项目要不要接"的判断标准。**

| 信号 | 判断 |
|---|---|
| 老板能说出具体痛点（"每天下午 3 点销售数据才汇总上来"） | 🟢 强信号 |
| 老板只说"我们要数字化/要 AI" | 🟡 需挖掘 |
| 有一个人愿意提供样本并花时间验证 | 🟢 强信号 |
| "你做好了我们试用"——没有人明确负责 | 🔴 弱信号 |
| 数据在 Excel/微信/ERP 导出里，格式相对固定 | 🟢 强信号 |
| 数据完全靠人记、格式每次不同、没有电子版 | 🟡 先做数据化，暂不做 AI |
| 第一版能嵌入现有工具（Excel、企微、钉钉） | 🟢 强信号 |
| 第一版就要换系统或全员培训 | 🔴 阻力大，先缩小范围 |
| 有人能复核 AI 输出（比如主管检查推荐结果） | 🟢 强信号 |
| AI 输出直接影响钱/安全/合规，无人复核 | 🔴 不做或降级为 L1 可视 |

## 这些模式对 FDE skill 的改进方向

当前 skill 有方法论但缺具体抓手。这些模式应该变成：

1. **可填空的模板**（不是"怎么写都可以"的空白模板，而是带例子、带选项的填空模板）
2. **可检查的清单**（FDE 每次进项目按清单打勾）
3. **可对照的案例卡片**（"你的情况和中山五金类似，建议先做客户分级"）
4. **可演示的数据样例**（模拟 Excel、模拟聊天记录，让新 FDE 能上手练习）
